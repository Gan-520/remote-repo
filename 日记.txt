compile 是默认的依赖范围。使用此范围的依赖在所有的构建阶段都可用，并且会被打包到最终的项目中。这意味着这些依赖对于编译、测试和运行时都是必需的。
provided (被提供的) 范围表示该依赖在编译和测试阶段是需要的，但在运行时由运行环境提供。典型的例子是 Java Servlet API，因为在 Servlet 容器（如 Tomcat）中已经提供了该 API 的实现，所以不需要将其打包到最终的项目中。
test ：范围表示该依赖仅在测试编译和测试运行阶段可用，在正常的编译和运行时不会被包含。常见的测试框架如 JUnit 就使用 test 范围
runtime（JDBC ）：可以避免在编译时引入不必要的依赖，减小项目的编译时间和依赖体积，同时确保在运行时能够正确加载所需的数据库驱动。
